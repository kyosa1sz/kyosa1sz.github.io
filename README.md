# Mochamad Farid - Portfolio Website

Personal portfolio website built with HTML, CSS, and Vanilla JavaScript. Hosted on GitHub Pages.

## Live Demo

[https://kyosa1sz.github.io/portofolio](https://kyosa1sz.github.io/portofolio)

## Features

- Colorful creative design with animated gradient backgrounds
- Particle canvas animation in the hero section
- Typed text effect cycling through roles
- Scroll-reveal animations for skill cards
- Animated skill progress bars
- Project filter by category (Frontend / Full Stack / Backend)
- Contact form with mailto integration
- Responsive for mobile, tablet, and desktop
- Smooth scrolling navigation with active section tracking
- Back to top button

## Tech Stack

- HTML5
- CSS3 (custom properties, animations, grid, flexbox)
- Vanilla JavaScript (ES6+)
- Font Awesome 6 (icons)
- Google Fonts (Poppins, Space Mono)

## Deploying to GitHub Pages

1. Push this repository to GitHub
2. Go to **Settings** > **Pages**
3. Under **Source**, select `main` branch and `/ (root)` folder
4. Click **Save** — your site will be live at `https://<username>.github.io/<repo-name>`
